# the-data-center-stack
A shared framework for understanding how the major functions of the data center industry fit together.

![The Data Center Stack](./the-data-center-stack-v1-0.png)

## Overview

The data center industry is highly interconnected, but there is no widely shared framework for explaining how its major functions relate to one another.

The Data Center Stack organizes those functions into six layers, moving from the physical facility to the digital workloads it supports.

The goal is not to classify companies. Most organizations operate across several layers.

The goal is to create a common language for customers, technicians, project managers, executives, partners, students, and other professionals working across the data center ecosystem.

## The Six Layers

1. **Foundation**  
   Land, power, water, structure, and the physical facility everything else depends on.

2. **Infrastructure**  
   The physical and digital building blocks: compute, storage, network, power, cooling, connectivity, security, and software.

3. **Deployment**  
   Receive, stage, install, integrate, relocate, and decommission infrastructure across its lifecycle.

4. **Operations**  
   The continuous work that keeps production infrastructure reliable and available through monitoring, security, maintenance, and optimization.

5. **Platform**  
   The abstraction layer that makes physical infrastructure consumable through virtualization, orchestration, and cloud services.

6. **Workloads**  
   Applications, AI, SaaS, and enterprise services that generate value and drive outcomes.

## Principles

The framework is built around four principles:

1. Each layer depends on the one below it.
2. The stack represents functions, not companies.
3. No layer is optional. Layers can be outsourced, but never skipped.
4. Some functions span every layer. Security, connectivity, and compliance appear throughout the stack.

## Version 1.0

This is the first published version of the framework.

It is intended to be refined through discussion, practical use, and feedback from people working across the industry.

Questions, critiques, and suggested revisions are welcome through GitHub Issues.

## Using the Framework

The Data Center Stack may be used in:

- Training and onboarding
- Presentations and educational material
- Industry discussions
- Project planning
- Customer and executive communication
