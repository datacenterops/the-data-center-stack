# Changelog

All notable changes to the Data Center Stack Industry Taxonomy should be documented here.

The taxonomy uses semantic versioning where practical:

- **MAJOR** — breaking classification or ID changes
- **MINOR** — new industries, groups, or material taxonomy additions
- **PATCH** — definition clarifications, keyword changes, typo fixes, or non-breaking metadata updates

## [0.1.0] — Draft

### Added

- Initial six-layer industry taxonomy
- 88 core industry definitions
- 15 Ecosystem Enabler classifications
- Permanent taxonomy IDs
- Industry groups
- Definitions
- Inclusion and exclusion criteria
- Common specialties
- Classification keywords
- AI classification rules
- JSON and CSV derivative formats
- Example company classifications

### Status

Draft for validation against real-world company datasets before the first stable release.
